빌라노트 개인정보처리방침

시행일: 2026년 10월 7일

빌라노트(이하 "앱")는 빌라 수리·관리 업무(일정, 민원, 수리비 청구)를 기록하는 앱입니다. 이 방침은 앱이 어떤 정보를 다루고, 어디에 저장하며, 누구와 공유하는지 설명합니다.

1. 수집·저장하는 정보

사용자가 직접 입력하거나 촬영한 정보만 다룹니다.

  • 빌라 이름·주소, 호수, 작업 내용, 일정 날짜·시간
  • 세입자·건물주 등의 이름과 전화번호 (사용자가 입력한 경우)
  • 현장 사진, 메모 사진
  • 수리비 청구 내역, 입금 계좌 (사용자가 입력한 경우)
  • 음성 입력 내용 (일정 등록 시 글자로 바뀐 내용)

2. 저장 위치

모든 기록은 사용자의 휴대폰 안(브라우저 저장소)에만 저장됩니다. 앱 개발자는 서버를 운영하지 않으며 사용자의 기록을 받거나 볼 수 없습니다. 기록은 사용자가 앱 데이터를 지우거나 앱을 삭제하면 함께 삭제됩니다.

3. 외부로 전송되는 경우

기능전송되는 정보받는 곳
AI 사진 분석·AI 일정 정리 (사용자가 설정에서 본인 API 키를 넣은 경우에만)분석할 사진 또는 글Google (Gemini API) 또는 Anthropic (Claude API) — 사용자가 고른 곳
음성으로 일정 등록음성휴대폰 기본 음성인식 서비스 (예: Google)
사진 글자 인식 (AI 키가 없을 때)없음 — 휴대폰 안에서 처리 (인식용 데이터만 내려받음)-
문자·전화사용자가 확인 후 직접 보내는 문자·전화휴대폰 기본 문자·전화 앱

AI 기능에 쓰이는 API 키는 사용자의 휴대폰에만 저장되며, 전송된 내용은 각 회사의 개인정보처리방침에 따라 처리됩니다.

4. 권한

  • 카메라·사진: 현장 사진, 메모 사진 인식
  • 마이크: 말로 일정 등록

권한은 해당 기능을 쓸 때만 요청되며, 거부해도 나머지 기능은 사용할 수 있습니다.

5. 제3자 제공·광고

앱은 사용자 정보를 판매하거나 제3자에게 제공하지 않으며, 광고·분석 도구를 사용하지 않습니다.

6. 아동

앱은 업무용이며 만 14세 미만 아동을 대상으로 하지 않습니다.
