# 빌라노트 🏠

빌라 수리·관리 업무용 모바일 웹앱 — 일정, 민원, 수리비 청구를 한 곳에서.

## 주요 기능
- **일정 관리**: 달력, 예약·완료·취소, 전화/문자 바로가기, 휴대폰 캘린더 추가(30분 전 알림)
- **말로 일정 등록**: 음성인식 + (선택) Claude AI 분석으로 빌라·호수·날짜·시간·연락처 자동 입력, 여러 건 동시 등록
- **사진 → 글자 변환**: 메모·문자 캡처를 찍으면 한글 OCR(Tesseract.js) 후 전화번호·날짜·시간·호수 자동 인식
- **민원 처리**: 접수 → 처리중 → 완료, 현장 사진, 방문 일정 연결
- **수리비 청구**: 품목별 청구서, 부가세, 청구 문자 자동 작성, 입금 확인
- **문자 양식**: 방문 안내·완료 안내 등 템플릿 자동 채우기
- **백업**: JSON 파일로 저장/불러오기

## 사용 방법
`index.html` 하나로 동작하는 정적 웹앱입니다. https 주소(GitHub Pages 등)로 열고
휴대폰 브라우저에서 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

- 데이터는 각 휴대폰 브라우저(IndexedDB)에만 저장됩니다. 기기 변경 전 백업하세요.
- AI 분석을 쓰려면 앱의 설정 › AI 연결에 본인 Claude API 키를 입력하세요. 키는 기기에만 저장되며 저장소에는 포함되지 않습니다.
